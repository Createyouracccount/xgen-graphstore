# ADR-002 — 라우터는 두 번째 백엔드와 동시 도입(지금은 구현 안 함)

- 상태: 채택 (2026-08-15)

## 결정
라우터(요청→저장소 선택: dual-write, 테넌트/도메인별 분기)를 **이 리포에서 구현하지 않는다.**
`create_store(config)` 팩토리(백엔드 1개 선택)까지만 제공한다.

## 이유
라우터는 저장소가 **둘 이상 공존**할 때만 의미가 있고, 두 번째 백엔드 없이는 테스트조차 불가하다.
지금 동인은 "RDF↔LPG 교체 가능성 확보"이지 "동시 병행 운영"이 아니다.
CLAUDE.md: 요청하지 않은 configurability 금지.

## 계획
- **0.2.0** Neo4j 백엔드(=3층 착수) 도입 시, 팩토리 위에 라우팅 층을 얹는 설계 여지를 남긴다.
- dual-write/마이그레이션 병행·테넌트 분기 요구가 실제로 생기면 **0.3.0**에서 라우터 구현.
- 그때까지: 인터페이스 1개 + 구현 N개 + 팩토리로 충분.
